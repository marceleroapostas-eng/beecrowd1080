# Beecrowd 1080 - Maior e Posição

## Descrição

Programa desenvolvido em Java que lê 100 valores inteiros e identifica o maior valor informado, apresentando também a posição em que ele foi encontrado.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

O programa recebe 100 números inteiros, positivos e distintos.

## Saída

O programa apresenta o maior valor lido e a posição em que ele foi informado.
